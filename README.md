# Operadores
Este projeto foi desenvolvido em Python com foco em tratamento e análise de dados de chamadas de operadores, visando identificar padrões de produtividade e propor melhorias operacionais. Foi realizado:
Tratamento de Dados: Conversão de tipos de dados, remoção de duplicados, substituição de valores nulos.
Análise Exploratória: Classificação da produtividade dos operadores, segmentação por tempo de espera, chamadas perdidas, realizadas e recebidas, Cálculo do tempo médio de atendimento e dias ativos, Identificação dos operadores mais produtivos via percentis, e gráficos em Matplotlib para visualização de dados, como: Produtividade (baixa, média, alta), Produtividade vs tempo de espera e Produtividade vs chamadas perdidas. 
Análise Descritiva: Cálculo de média e variância, como: Produtividade (chamadas feitas e recebidas), Tempo de espera, Taxa de chamadas perdidas
Testes de Hipóteses: Diferença no tempo de espera entre operadores mais e menos produtivos e diferença na taxa de chamadas perdidas entre operadores.
Conclusões: Evidência de desigualdade de produtividade entre operadores e tempo de espera varia significativamente entre chamadas. 
Sugestões: Adicionar mais operadores em horários de pico, implementar retorno automático em filas altas, distribuir melhor as chamadas para reduzir perdas e criar alertas em tempo real para chamadas perdidas.
